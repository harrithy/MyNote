## 🔥 核心难点、关键代码与攻坚复盘

### 1. 同一位置的多张现场照片不能相互覆盖

**涉及文件**：`scenePhotoLayerConfig.ts`、`scenePhotoPopup.vue`。**难点所在**：逐图打点会堆叠图标，而合并点位后仍需保留全部照片。

**关键代码**（`scenePhotoLayerConfig.ts` 真实节选）：

```ts
/**
 * 生成现场图片坐标分组键（按香港1980 X/Y 坐标合并同位置点位）
 * @param x 香港1980 东坐标
 * @param y 香港1980 北坐标
 * @returns 坐标分组键
 */
const getCoordKey = (x: unknown, y: unknown): string => `${Number(x)}_${Number(y)}`
```

**攻坚方案**：过滤无效坐标，按相同 X/Y 合并点位；点击后从原列表取出该坐标的全部图片，按上传时间倒序轮播，补充加载、失败和空态。这里只合并完全相同的坐标，不代表邻近点聚合。

### 2. 交通实时流与供水区范围仍需明确关联

**涉及文件**：`roadSpeedLayer.ts`、`trafficCameraLayer.ts`。**难点所在**：页面缓存和图例切换需要启停实时资源，也不能把已有交通数据误写成按当前供水区筛选。

**关键代码**（`roadSpeedLayer.ts` 真实节选）：

