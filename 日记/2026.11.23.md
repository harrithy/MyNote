### 1. 旧请求返回时页面可能已切走

- **涉及文件** 管网详情页 `index.vue`、`monitorTagData.ts` 和 `scenePhotoLayerConfig.ts`。
- **难点所在** 暂停定时器只能阻止新请求。已经发出的查询仍可能在离开页面、切换供水区或更换传感器后返回。
- **关键代码（节选）**

```typescript
/** 停止定时刷新，并使当前供水区尚未完成的查询失效。 */
const pausePanelRefresh = () => {
    pausePanelPolling()
    initRequest += 1
    tagDataRequest += 1
    invalidateWaterCutOffNoticeRequest()
}
```

- **攻坚方案** 停用或卸载页面时暂停轮询并递增请求序号。照片使用自己的序号，面板应用合并结果前再校验点位和 IOT 模式。切回缓存页时恢复定时器并立即刷新。
