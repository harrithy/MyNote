## 🔥 核心难点、关键代码与攻坚复盘

### 1. HTTP 成功不代表宿主已经成功打开文件

**涉及文件**：插件 `client.js`、`index.js`。**难点所在**：响应体挂起、非 JSON 响应或业务失败，会让前端长时间等待或错误提示成功；自动重试启动、更新又可能重复执行操作。

**关键代码**：已核对 `requestJson`、`openTarget` 与 `applyUpdate`。**攻坚方案**：超时覆盖响应头和 JSON 读取，要求对象响应及明确的 `ok/path`；相同打开请求去重，失败后可手动重试和重新探测，不自动重试有副作用的请求。Git 更新只允许安全快进条件成立时继续。

### 2. 水质异常判断从最大值调整为平均值优先

**涉及文件**：水质分析 `config.ts`、`districtData.ts`。**难点所在**：分布数据与统计规则需使用相同取值，平均值为零也不能被当作缺失。

**关键代码**（`config.ts` 真实节选）：

```ts
/**
 * 异常判断取值：优先平均值（分布接口返回 average），接口未返回平均值时回退最大值
 * @param stat 参数统计值
 * @returns 用于档位判断的数值
 */
const getJudgeValue = (stat: DmWqParameterStatVo): number | null => stat.averageValue ?? stat.maxValue
```

**攻坚方案**：分区、TPU 和采样点共用取值方法，再按已勾选参数判断；保留无数据分支。该规则代码的作者日期为 11 月 10 日，今日首次进入本地快照，按今日引入记录。
