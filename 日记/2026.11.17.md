## 🔥 核心难点、关键代码与攻坚复盘

### 1. 快速切换不能留下模型或破坏共享贴图

- **涉及文件**：`mascotLive2D.ts`、`MascotLive2DStudio.tsx`。
- **难点所在**：模型异步加载可能晚于页面退出；渲染库又按 URL 缓存贴图，重复加载与销毁需要协调。
- **关键代码**（加载队列节选）：

```typescript
// Pixi 按 URL 缓存纹理；串行完成旧加载的清理，避免快速切换时销毁新模型共享的贴图。
const previousLoad = modelLoadQueue;
let releaseLoad!: () => void;
modelLoadQueue = new Promise<void>((resolve) => { releaseLoad = resolve; });
```

- **攻坚方案**：初始化先等待前一加载任务并预检贴图；失败或取消时销毁已创建模型，队列在 `finally` 释放。组件退出时中止并清理控制器，迟到结果同样立即销毁。

### 2. 绘制范围、建筑显隐与统计保持一致

- **涉及文件**：`editor.vue`、`noticeMap.ts`、`scheme.ts`。
- **难点所在**：范围变化后沿用旧分析，或隐藏建筑后仍计入方案，都会造成显示与统计不一致。
- **关键代码**：`resetAnalysis()` 清空建筑、水表及纳入标记；`getSchemeStatistics()` 排除隐藏建筑及其水表和人口。
- **攻坚方案**：新增或清空范围即使旧分析失效，保存时重新计算纳入建筑；缓存页仅响应当前编辑路由，离开时取消绘制，卸载时释放绘制器与业务图层。
