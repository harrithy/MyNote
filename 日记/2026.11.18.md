## 🔥 核心难点、关键代码与攻坚复盘

### 1. 缩放手势与点击留白关闭互不干扰

- **涉及文件**：`imageViewer.ts`、`MediaPreviewViewport.tsx`。
- **难点所在**：竖图两侧留白也在媒体容器内，拖拽、捏合结束还可能产生点击，不能直接按容器点击关闭。
- **关键代码**（点击判断节选）：

```typescript
// 拖动、捏合或从图片上开始的点击不关闭；加载失败时保留重试按钮。
if (event.target instanceof Element && event.target.closest("button, a, input")) return;
if (event.detail > 0 && (gesture.current.moved || gesture.current.startedOnImage)) return;
if (!isOnImage(event.clientX, event.clientY)) onBackgroundClick();
```

- **攻坚方案**：按图片自然尺寸和当前变换判断真实边界，以指针为焦点缩放并约束平移；记录手势起点和移动状态，原生滚轮监听拦截页面滚动，视频保留原生控件交互。

### 2. 删除建筑不能留下水表或纳入标记

- **涉及文件**：停水榜 `editor.vue`、`scheme.ts`。
- **难点所在**：建筑、水表结果及纳入列表分开保存，只删界面行会造成统计残留。
- **关键代码**：`handleBuildingRemove()` 同步移除建筑、对应 `buildingId` 水表和纳入 ID。
- **攻坚方案**：删除与显隐均受只读、绘制及分析状态约束，统计从当前可见建筑重新计算；不把演示删除写成后端数据删除。
