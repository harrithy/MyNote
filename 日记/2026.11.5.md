## 🔥 核心难点、关键代码与攻坚复盘

### 1. 上传失败后重试仍引用失效的内存记录

**涉及文件**：`uploadRegistry.ts`、`pendingReferenceUploads.ts`、`jobQueue.ts`。**难点所在**：输入面板移除图片可能影响已入队任务；旧 uploadKey、已完成的公网地址与本地占位混存，也会让重试重复报错。

**关键代码**（`uploadRegistry.ts` 真实节选）：

```ts
/**
 * 当上传任务处于失败终态且登记了重试工厂时，重新触发上传。
 */
retryFailedUpload(key: string): boolean {
  const entry = this.uploads.get(key);
  if (!entry || entry.status !== "rejected" || !entry.retryFactory) {
    return false;
  }
  this.bindPromise(entry, entry.retryFactory());
  return true;
}
```

**攻坚方案**：保留队列所需的上传登记，用重试工厂重新上传；记录丢失时，仅对仍可读取的 blob 尝试恢复。页面刷新后源文件与 blob 均失效的情况仍不能据此保证恢复。

### 2. 合并几何需要与列表对象身份保持一致

**涉及文件**：`zones.ts`、`supplyZoneLayerConfig.ts` 及几何 API。**难点所在**：当前接口按类型与编码合并多个供水 ID，`supplyId` 改为可选数组，精确查询不返回该字段。
