## 🛠️ 核心工作与实现

### 1. 批量生成结果保存与续查

- **分批保存**（28913a4）并发查询未结束的子任务。任一任务返回成功或失败终态后，按远程 ID 串行写回同一条任务记录。已生成的媒体、文本和结构化数据随结果保存。

## 🔥 核心难点、关键代码与攻坚复盘

### 1. 子任务分次返回时维护同一个生成版本

- **涉及文件** `jobQueue.ts`。
- **难点所在** 一批结果的返回顺序可能和任务顺序不同。若每次保存都追加历史主图，同一批结果会被拆成多个版本。
- **关键代码（节选）**

```ts
const savedResults = new Map(Object.entries(job.remoteTaskResults ?? {}));
const orderedResults = () => taskIds.map((id) => savedResults.get(id)).filter((result) => result !== undefined);
const hasSavedPrimary = getSucceededResults(orderedResults()).some((result) =>
  Boolean(getPrimaryMediaUrl(normalizeSucceededAssets(result, job)))
);
const outputImages = getJobOutputImages(job);
// 同一批子任务共享一个历史版本，分次返回时只更新这个版本的主图。
const previousImages = hasSavedPrimary ? outputImages.slice(0, -1) : outputImages;
```

- **攻坚方案** 按原任务 ID 顺序汇总已完成结果。该批首次生成主图后，后续回写只替换这一批的主图，保留之前的历史版本及该批成功结果。

### 2. 多个停水范围共享同一统计条件

- **涉及文件** `noticeMap.ts`、`editor.vue`。
- **难点所在** 多个区域重叠时，分别查询再汇总可能重复计算交叠区的水表和楼栋。
- **关键代码（节选）**

```ts
const geometries = ranges.map(toMapGeometry)
// 合并重叠区域，让同一个楼栋或水表要素只计数一次。
const geometry = geometries.length === 1 ? geometries[0] : geometryEngine.union(geometries)
if (!geometry) {
	throw new Error("无法合并停水范围")
}
```

- **攻坚方案** 合并多边形后，以同一空间条件查询水表总数、分类数量及楼栋。各路结果独立处理，单项查询失败时仍可回填其他成功项。
