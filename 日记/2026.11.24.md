## 🔥 核心难点、关键代码与攻坚复盘

### 1. 隔离不同照片的登记请求

- **涉及文件** PhotoSyncDialog.vue。
- **难点所在** 切换照片重新打开弹窗后，上一张图片的异步响应可能晚于新请求返回。
- **关键代码（节选）**

```ts
// 弹窗已关闭或已重新打开时丢弃过期响应
if (seq !== querySeq || !visible.value) {
	return
}
```

- **攻坚方案** 每次打开时重置表单及请求序号，查询和保存的旧响应都不能回填当前弹窗。状态查询失败时禁用确认。

### 2. 把定位时间写进照片像素

- **涉及文件** image-upload.vue、im-photo-watermark.js。
- **难点所在** 竖拍、倒拍和镜像照片带有方向信息，直接绘制可能把水印放到可见画面的其他位置。
- **关键代码（节选）**

```js
// 半透明深色底配白色文字，时间直接合成到图片中，在明暗背景上均可辨认。
paint.setARGB(160, 0, 0, 0);
canvas.drawRect(margin, margin, margin + textWidth + 2 * padding,
  baseline + Number(paint.descent()) + padding, paint);
paint.setARGB(255, 255, 255, 255);
canvas.drawText(text, margin + padding, baseline, paint);
```

- **攻坚方案** 先按 EXIF 归正压缩图，再把定位成功时间绘制到左上角，另存 JPG 并复查体积。水印生成或大小校验失败时停止该图上传。
